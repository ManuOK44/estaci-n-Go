# Estación Go
App independiente, adaptable y utilizable sin conexión una vez cargada. Tiene Mis ganancias (envío y propina), repartidores independientes sin propinas, estadísticas diarias/semanales/mensuales, historial filtrado por fecha, edición/borrado de pedidos, archivo y eliminación permanente de repartidores, respaldo JSON y tema claro/oscuro.

## Publicación
Publica estos archivos en la raíz de un **repositorio nuevo**, separado de `mis-cobros`, y activa GitHub Pages desde `main` / raíz. Los datos se guardan **localmente en cada navegador/dispositivo** y no se sincronizan: exporta respaldos con regularidad. No borres el almacenamiento del sitio sin respaldo. Los cambios de dispositivo requieren exportar/importar el archivo JSON.
